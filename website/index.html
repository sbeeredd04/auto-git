About

Auto-Git is a cross-platform CLI tool and VS Code extension that revolutionizes your development workflow. It monitors your code changes, intelligently analyzes significance and completeness, and automatically generates meaningful commit messages using AI.

Built for developers who value automation and efficiency, Auto-Git eliminates the cognitive overhead of writing commit messages while maintaining high-quality version control practices.

Configuration

vpn_key API Key Setup

Get your Gemini API key from Google AI Studio

For CLI:

export GEMINI_API_KEY="your-api-key"

For VS Code:

  1. Open Settings (Cmd/Ctrl+,)
  2. Search "GitCue API Key"
  3. Enter your API key
